# 个人画廊 · Personal Gallery

Windows 本地图片与提示词素材管理工具。把参考图按素材库、画风和主题整理，支持跨库搜索、复制图片与提示词、备份恢复及公开来源增量导入。

## 下载与启动

1. 在 [Releases](https://github.com/Ginwow/personal-gallery/releases/latest) 下载 **PersonalGallery-Windows-x64.zip**，完整解压到可写的文件夹。
2. 双击 **个人画廊.exe**，通过“新建本地库”导入自己的第一组图片。

无需安装 Python。本地建库、浏览、整理和复制无需联网，也不需要 API 密钥。程序不负责生成图片。

首次启动是空白画廊，**不附带作者的图片、提示词库、数据库、配置、日志或密钥**。不要在 ZIP 内直接运行，也不要只取出 EXE；必须保留同级 `_internal` 文件夹。

## 建立和管理素材库

首页几个入口的用途不同：

| 入口 | 用途 |
| --- | --- |
| 新建本地库 | 用自己的图片创建一个新库，全程离线 |
| 添加已有库 | 将已有的个人画廊素材库登记到首页 |
| 新增素材库 | 从受支持的 GitHub 来源下载并创建新库，需要联网和翻译配置 |
| 检查全部更新 | 检查已登记来源的库是否有新增内容 |

### 新建本地库

1. 点击“新建本地库”，选择至少一张图片。
2. 输入首批图片的画风名称，例如“水彩插画”。
3. 选择一个**空文件夹**作为素材库位置。

全部图片导入成功后，新库才会出现在首页。支持 JPG、JPEG、PNG 和静态 WebP；不建立空库。

### 添加已有库

点击“添加已有库”，选择包含 `gallery.sqlite3`、`originals/` 和 `thumbnails/` 的素材库文件夹。普通图片文件夹应使用“新建本地库”，不能直接作为已有库添加。

单击首页卡片进入库。右键卡片可以选择封面、修改显示名称、重新定位、设置来源，以及“从首页移除（保留文件）”。移除登记不会删除图片；重命名卡片不等于移动磁盘文件夹。

## 导入图片与整理画风

进入素材库后，点击“＋ 导入图片”，或将图片文件拖入库内窗口：

1. 选择归入已有画风，或新建画风并填写名称。
2. 可选填写统一主题标签，多个标签用逗号分隔。
3. 确认导入。相同图片会报告为重复，不重复收录。

每张图片必须属于一个画风。画风用于收集一组具有共同视觉表现的参考图，每张图另有自己的完整提示词和主题标签。

- **编辑画风**：修改名称、共性提示词和画风标签。
- **编辑图片信息**：修改该图完整提示词和主题标签；修改后点击“保存”，取消不会写入。
- **批量主题标签**：多选图片后，给所选图片追加主题标签。
- **标签管理**：分别管理画风标签和主题标签，支持重命名、合并和删除。
- **右键图片**：可设为画风封面、移动所选图片到其他画风、删除所选图片。
- **调整顺序**：进入一个画风，在未开启搜索或标签筛选时拖动图片排序。
- **缩略图大小**：通过库内工具栏滑块调整。

Ctrl / Shift 可配合点击多选图片。删除会移除**素材库内的副本**；最后一张图删除或移出后，对应空画风也会删除。右键删除整个画风会连同该组图片一起删除，请查看确认提示。

## 搜索与标签筛选

### 首页跨库搜索

在首页输入关键词，按 Enter 或点击“搜索”，在已添加的素材库中查找。结果显示所属库，点击图片打开详情。

搜索匹配画风名称、图片文件名、画风标签和主题标签；**不搜索长提示词，不自动翻译关键词**。多个词以空格分开，要求全部匹配。返回首页后可继续原搜索，点击“清除”恢复库列表。

### 库内搜索

进入素材库后，可将文字搜索与“画风标签”“主题标签”组合使用：

- 画风标签单选，主题标签可多选。
- 多个选中标签默认要求全部匹配。
- 选中标签会显示在搜索栏，点击标签即可取消。
- **搜索文字为空时，按 Backspace（退格）或 Delete 删除最后一个标签**；有文字时保持正常文字编辑行为。
- 用 Tab 聚焦到某个标签后，退格或 Delete 可删除该标签。
- 点击“清除”重置文字和标签筛选。

标签只有两个平级维度：**画风**描述表现形式，例如水彩、油画、写实摄影；**主题**描述实际画面元素，例如人物、动物、建筑、食物。各库标签独立管理。

## 图片详情与复制

点击组内图片或搜索结果打开详情。左侧是大图，右侧是提示词：

| 操作 | 说明 |
| --- | --- |
| 复制图片 | 将原尺寸图片内容放入系统剪贴板，保留透明度和显示方向，可粘贴到支持图片的应用 |
| 复制完整提示词 | 优先复制中文部分；没有中文时复制原文，属于当前图片 |
| 复制画风提示词 | 复制该图片所属画风的共性提示词，适合复用整组画风 |
| 编辑图片信息 | 编辑该图提示词和主题标签 |

中文与原文分别显示；没有结构化分段的提示词按现有内容展示。可拖动图片和文字间的分隔条、调整字号、展开“来源说明”，阅读偏好会保存。

复制成功后按钮会短暂显示“已复制”反馈。复制图片需要目标软件支持从剪贴板粘贴图片；它不是复制图片文件路径，也不会生成新图片。

## 从公开来源新增素材库

“新增素材库”用于**新建来源库**，已有来源库补充图片应使用“检查更新”。

1. 先完成下文“翻译设置”，按需要配置“GitHub设置”。
2. 点击“新增素材库”，填写受支持的 **GitHub 仓库主页地址**，不要填写单个文件或帖子地址。
3. 程序读取来源并显示候选图片数，确认下载与可能产生的 API 费用。
4. 选择新库的父文件夹，程序会在其中按来源名创建新目录；已有同名目录不会覆盖。下载图片、翻译完整提示词并处理标签，整批成功后添加到首页。

当前代码适配以下来源；适配不代表保证其上游文件或外部图片始终可访问：

| 来源 | 仓库地址 |
| --- | --- |
| NanoBanana Pro | https://github.com/ZeroLu/awesome-nanobanana-pro |
| Callirra Atlas | https://github.com/callirra-ai/gpt-image-2-5-prompt-atlas |
| YouArt | https://github.com/youart-open-source/awesome-gpt-image-2-5-prompts |
| Vulcan | https://github.com/vulcaneon/awesome-gpt-image-2.5-prompts |
| Freestylefly | https://github.com/freestylefly/awesome-gpt-image-2 |
| Spsrx | https://github.com/spsrx000000-crypto/awesome-gpt-image-2 |
| Handraw | https://github.com/yang0/handraw-style |
| Vigo | https://github.com/vigozhao/ai-visual-prompt-cookbook |

暂不支持输入任意仓库自动解析。来源文件结构变化、图片失效或格式不匹配时会报告错误，不会把失败视为“没有更新”。来源收录的模型声明和图像效果不等于本程序已独立复现；涉及参考图、占位符和步骤要求时，请查看原文与来源说明。

## 检查和应用来源更新

- **单库检查**：进入库后点击“当前库来源 ▾ → 检查更新”，或右键首页卡片打开来源操作。
- **全部检查**：首页点击“检查全部更新”。仅检查不会调用翻译或图像识别 API；确认下载更新后才进行处理。
- **检查进度**：底部显示来源进度和耗时，后台检查期间可继续浏览。
- **确认更新**：查看新增图片与标签变化数量，再确认下载及翻译。

每个库采用“准备 → 校验 → 整批提交”的流程。任一条下载、翻译或必要识别失败，该库整批不更新；多库之间独立成功或失败。重试复用有效缓存。

当前库仍在浏览时，可能显示“已准备完成”。从“当前库来源 ▾ → 应用已准备的更新”提交；程序会关闭该库详情并返回首页。其他程序实例也占用该库时，先退出占用实例再应用。准备后若发生本地修改，旧计划不会直接覆盖这些修改，需要重新准备。

更新保留已有完整提示词和本地校对结果，不重扫旧图。新增图片优先使用可靠映射到本地画面元素主题的源标签；缺少可靠内容标签时才按图识别。商业、教育、科技等用途分类不能直接当作画面主题。

主动删除的来源图片默认视为忽略，不会在每次更新时自动下载回来。需要恢复时，从来源菜单选择“恢复已忽略图例”，再检查更新。已有来源的补图会加入对应画风。

卡片的“最近一次更新”记录成功导入或应用来源更新的时间，不是最近检查时间。更新后返回首页或重新搜索即可刷新结果。

## GitHub 与 DeepSeek 设置

### GitHub 设置：访问来源

点击顶部“GitHub设置”：

1. 可不填 Token，使用匿名访问。
2. 遇到 GitHub 请求额度不足时，可填写自己的 Token，提高可用额度。
3. 点击“测试连接与额度”查看当前剩余次数和重置时间，再点击“保存”。

仅需公开仓库只读访问，不需要仓库写入权限。留空保留已保存 Token；勾选删除 Token 并保存可恢复匿名访问。测试当前输入不会自动保存。

Token 存在本机 Windows 凭据管理器中。程序不会读取本仓库发布者的登录信息，也不会替下载者提供 Token。

### 翻译设置：翻译与必要的图片识别

点击顶部“翻译设置”，填写：

| 字段 | 填写方式 |
| --- | --- |
| API 地址 | 服务提供的 HTTPS 基础地址；不要自行追加 `/chat/completions` |
| 模型 | 当前账号实际支持的翻译模型名称 |
| 看图模型 | 服务实际支持图片输入的模型名称；界面预填值需按服务可用情况核实 |
| API 密钥 | 自己账号的 API Key；留空保留已保存密钥 |

点击“测试连接”会分别测试翻译和图片核验，**可能消耗 API 额度并计费**；通过后点击“保存”。仅模型名字类似或接口兼容，不代表其支持看图；返回不支持图片、无法识别或结果结构不完整时，不会跳过校验强行导入。

源提示词保留原文与来源，中文翻译明确标为自动翻译；占位符、参数、明确要求渲染的文字按规则保留。机器翻译及识别仍可能出错，可以在详情中手动修正。

密钥存于 Windows 凭据管理器，不写入素材库或备份。移动程序或换电脑后需要重新配置密钥。普通本地图片导入不需要这些设置。

## 备份恢复与迁移

### 备份

进入素材库，点击“更多操作 ▾ → 备份素材库…”，将 ZIP 保存到**该库以外**的位置。

备份包含原图、缩略图、元数据和来源映射，不包含 API 密钥、日志和更新缓存。每个素材库分别备份；建议另存一份到其他磁盘。

### 恢复

进入一个库，点击“更多操作 ▾ → 恢复备份…”，选择备份 ZIP，再选择新的空文件夹。恢复不会合并或覆盖已有库。校验完成后可选择打开；需要长期显示在首页时，返回首页用“添加已有库”登记恢复后的文件夹。

### 迁移到其他电脑

1. 关闭程序，复制整个程序文件夹以及所有外部素材库，或逐库使用备份恢复。
2. 保留 `settings.json`；程序目录内的库以相对路径记录，整体移动更方便。
3. 外部库位置变化后，右键卡片选择“重新定位”；若库仍打开，先重启程序。
4. 在新电脑重新填写 GitHub Token 和 API 密钥。

不要只复制 `gallery.sqlite3`，图片实际位于同库的 `originals/` 和 `thumbnails/`。同一素材库请勿同时由多个程序实例编辑。

## 升级程序

1. 关闭正在运行的个人画廊，先备份自己的素材库。
2. 下载新版 ZIP 并解压，替换 EXE、`_internal` 和说明文件。
3. **保留自己的 `settings.json`、`素材库/` 和其他外部素材库**，重新启动。

新发行包不附带用户配置或素材。不要为了升级而删除原程序目录中的个人数据。仅更新 README 不需要替换程序。

## 常见问题

| 现象 | 处理方法 |
| --- | --- |
| 第一次启动没有图片 | 发行包为空白版；新建本地库导入图片，或添加已有库 |
| “新增素材库”不能添加本地图片文件夹 | 本地图片请用“新建本地库”；“新增素材库”是公开来源导入入口 |
| HTTP 403 / GitHub 额度用完 | 查看 GitHub 设置中的剩余额度和重置时间；等待恢复或配置自己的只读 Token，避免连续重复检查 |
| 图片地址 403 / 404，或来源格式错误 | 不一定是 GitHub 额度问题；可能是外部图站限制、资源失效或上游结构变化。记录具体库名与错误后反馈 |
| 翻译成功但看图失败 | 检查所选模型是否支持图片输入、API 地址和服务权限；该库不会部分更新 |
| 提示素材库已被打开 / 无法提交 | 关闭另一个占用该库的程序实例；当前浏览中的库通过“应用已准备的更新”提交 |
| 搜索不到内容 | 检查当前标签是否过多、关键词语言是否一致；多个词与多个主题标签均要求全部匹配 |
| 复制图片后无法粘贴 | 确认目标应用支持粘贴图片；复制的是图片内容，不是文件路径 |
| 移动目录后卡片无法访问 | 右键素材库卡片重新定位；同时保留数据库、原图和缩略图 |

可在 [Issues](https://github.com/Ginwow/personal-gallery/issues) 反馈问题，附程序版本、Windows 版本、复现步骤和脱敏后的错误信息。不要上传自己的素材库、密钥或完整配置。

## 开发与构建

需要 Windows 与 Python 3.11：

```powershell
python -m venv .venv
.venv/Scripts/python.exe -m pip install -r requirements.txt
.venv/Scripts/python.exe main.py
```

测试与生成便携包：

```powershell
.venv/Scripts/python.exe -m pytest -q
.venv/Scripts/python.exe -m mypy gallery main.py
./build.ps1 -Release
```

生成 `dist/个人画廊/` 和 `dist/PersonalGallery-Windows-x64.zip`。也可通过 `-PythonExecutable` 指定 Python 路径。
